# AIANKIPRO - LLM Context

Site: https://aiankipro.com
Canonical: https://aiankipro.com/llm.txt

## Short Summary

AIANKIPRO solves a modern learning problem: people consume huge amounts of information, but it stays scattered and hard to remember.

AIANKIPRO turns scattered input into a focused loop:
- Generate cards from any topic
- Learn first in Linear mode (sequential pass)
- Use card chat or voice chat whenever you get confused, curious, or need deeper understanding while learning
- Switch to Smart mode for later recall review
- Reopen saved chat summaries, and continue in live card chat or voice chat when a hard card needs deeper understanding again

## What Is Implemented In Product

- Topic-based AI card generation.
- Draft editing and rewrite flow before final save.
- Draft autosave/resume for generation chats.
- Save cards to a new or existing deck.
- After save, app can open study in a guided first pass (`mode=linear`) using generated card order.
- Card-level tutor chat with persisted history.
- Chat summary generation for a card conversation.
- Voice mode in study:
  - voice commands (flip/next/previous/rate/open tutor/close tutor)
  - spoken answer handling
  - full voice study loop (AI can read cards, you answer aloud, and the app can evaluate/suggest rating)
  - spoken tutor interaction
  - spoken playback (premium voice when available, browser fallback otherwise)
